# Experiment No. 4

## 1. Experiment Title

Divs, Attributes and a Small Fix

## 2. Aim

Group page content with div elements, use id and data attributes, and correct malformed HTML.

## 3. Software / Tools Required

- Visual Studio Code or another text editor
- Git and a terminal (for the repository exercises)
- A web browser such as Chrome or Edge (for HTML/CSS exercises)

## 4. Theory

The div element groups content without adding semantic meaning by itself. The class attribute can label multiple elements, while id identifies one element in a document. Custom data-* attributes store information on an element. Properly nested and closed HTML elements create a reliable document structure.

## 5. Algorithm / Procedure

1. Create layout.html with header, main, and footer div blocks in that order.

2. Create attributes.html with a div id profile and a paragraph whose data-topic is hobbies.

3. Repair the supplied attendance markup and save the valid page as attendence-fixed.html.

## 6. Program / Queries / Commands


- Task 1: layout.html

- Task 2: attributes.html

- Task 3: attendence-fixed.html

## 7. Input

### Task 1
Text for the three layout blocks.

### Task 2
Paragraph text; data-topic value hobbies.

### Task 3
Supplied broken markup and the names/percentages Asha 92% and Rohan 85%.
