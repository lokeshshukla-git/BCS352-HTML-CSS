Subject: BCS352 – HTML and CSS Student Name: LOKESH SHUKLA Roll Number: 2510303281

--> Aim

To push commits to a second (bare) repository on the same computer and make a copy of it using clone.

--> Theory

A remote repository stores a shared copy of a project. git init --bare creates a repository without a working folder, git remote add origin links it, and git push sends commits to it. git clone creates a full copy of a repository along with its commit history.

--> Conclusion

I learned how to connect a remote repository, push commits to it, and clone it to get an identical copy.
