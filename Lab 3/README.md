# Experiment No. 3

## 1. Experiment Title

Your First HTML Page

## 2. Aim

Create basic HTML documents with a title, headings, paragraphs, text emphasis, and a line break.

## 3. Software / Tools Required

- Visual Studio Code or another text editor
- Git and a terminal (for the repository exercises)
- A web browser such as Chrome or Edge (for HTML/CSS exercises)

## 4. Theory

HTML structures web content with elements. A document typically contains a doctype, html, head, title, and body. Heading elements express hierarchy, p marks paragraphs, strong conveys importance, em adds emphasis, and br creates a line break.

## 5. Algorithm / Procedure

1. Create first.html with title “My First Page” and h1 “Hello, I am Asha”; open it in a browser.

2. Create headings.html with h1, h2, h3, and a paragraph.

3. Create text-format.html with two paragraphs, strong and em emphasis, and a line break inside a paragraph.

## 6. Program / Queries / Commands


- Task 1: first.html

- Task 2: headings.html

- Task 3: text-format.html


## 7. Input

### Task 1
Title and heading text specified in the task.

### Task 2
Your chosen heading and paragraph text.

### Task 3
Two paragraphs of your choice and one word each to emphasize.
