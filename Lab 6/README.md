--> Aim

To create unordered, ordered (with nesting) and description lists.

--> Theory

<ul> creates a bulleted list and <ol> creates a numbered list, with each item written in <li>. A list placed inside an <li> forms a nested list. A description list uses <dl>, with <dt> for the term and <dd> for its description.

--> Conclusion

I learned how to present information using the three types of HTML lists, including nested lists.
