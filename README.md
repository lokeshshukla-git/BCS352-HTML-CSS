# BCS352 HTML and CSS Introduction Lab

This repository contains 15 practical labs for the BCS352 HTML and CSS Introduction Lab. The work begins with Git basics and introductory HTML, then progresses through page structure, links, images, lists, forms, tables, CSS styling, Flexbox, Grid, and responsive design.

## Topics Covered

- Git repositories, commits, remotes, pushing, and cloning
- HTML structure, text, links, images, lists, forms, and tables
- CSS selectors, stylesheets, units, variables, and the box model
- Flexbox, CSS Grid, and responsive layouts with media queries

## Repository Structure

Each lab is stored in its own folder, from `Lab 1` to `Lab 15`. Lab folders contain the README, program files, and task output screenshots for that experiment.

## Tools

- Visual Studio Code
- Git and a terminal
- Microsoft Edge or Google Chrome

Open the HTML files in a web browser to view their rendered pages.
